# FixIT

FixIT es una plataforma web responsive orientada a conectar usuarios que requieren soporte técnico informático con técnicos independientes compatibles con su necesidad.

## Propósito

La plataforma permitirá registrar incidencias, realizar un triaje inicial, identificar técnicos compatibles según especialidad y ubicación, agendar servicios y gestionar progresivamente el ciclo de atención.

## Modalidades de atención

- Remota
- Presencial
- Pickup

## Stack tecnológico

- Frontend: React
- Backend: Node.js + Express
- Base de datos: PostgreSQL
- Gestión: Jira Software
- Diseño UX/UI: Figma
- Pruebas API: Postman
- Control de versiones: Git + GitHub
- Despliegue frontend: Vercel
- Despliegue backend: Render
